# MelkiCAD

**MelkiCAD** تطبيق CAD عربي بواجهة من اليمين إلى اليسار (RTL) لرسم مخططات الغرف والمنازل، يعمل كتطبيق ويب تقدمي (PWA) ويمكن تثبيته على الهاتف، مع غلاف Android مبني باستخدام Capacitor.

التطبيق مكتوب بـ JavaScript وCSS وHTML دون إطار عمل أو مكتبات تشغيل خارجية، ويمكنه العمل دون اتصال بالإنترنت بعد تحميله أول مرة.

## الميزات

### الرسم والتصميم
- رسم الخطوط والجدران والمستطيلات والدوائر والأقواس والبيضاويات والمضلعات وPOLYLINE.
- أدوات الالتقاط الهندسي (Snap) والقيود مثل Ortho والشبكة والزوايا.
- إدخال رقمي وإحداثيات دقيقة أثناء الرسم والتحرير.
- الأبعاد والنصوص، مع دعم عرض النص العربي.
- الطبقات: إنشاء الطبقات وإدارتها، إظهارها وإخفاؤها وقفلها، وتحديد عناصر طبقة معينة.
- لوحة خصائص لتعديل خصائص العناصر المحددة.

### التحرير وإدارة المشاريع
- تحديد العناصر وتحريكها ونسخها وتدويرها وتحجيمها ومحاذاتها.
- أدوات Stretch وBreak وFillet وChamfer وExplode وJoin.
- التراجع والإعادة مع سجل محدود للحفاظ على الأداء.
- إدارة عدة مشاريع، مع حفظ بيانات كل مشروع بصورة مستقلة.
- حفظ تلقائي محلي باستخدام IndexedDB، مع وضع احتياطي عند عدم توفره.

### الملفات والإخراج
- استيراد وتصدير المشاريع بصيغة JSON.
- استيراد وتصدير DXF، مع دعم ترميزات النصوص العربية الشائعة.
- إخراج PDF والطباعة مع إعدادات الورقة والاتجاه والمقياس وجدول العنوان.
- على Android، يدعم غلاف التطبيق مسارات الحفظ والمشاركة الأصلية.

### الهاتف والعمل دون اتصال
- واجهة متجاوبة للاستخدام على الهواتف والأجهزة اللوحية والحاسوب.
- دعم التفاعل باللمس والسحب.
- يعمل كتطبيق PWA، ويمكن تثبيته من المتصفح.
- ملفات التطبيق وخط IBM Plex Sans Arabic مضمنة محليًا؛ لا يحتاج التطبيق إلى تحميل مكتبات أو خطوط من الإنترنت أثناء التشغيل.

## البنية

```

  js/00-storage.js   التخزين: IndexedDB، الترحيل من localStorage، والوضع الاحتياطي
  fonts/             خط IBM Plex Sans Arabic مع ترخيص OFL

```

## التشغيل محليًا

يتطلب تشغيل أدوات المشروع Node.js 18 أو أحدث، كما يتطلب خادم التطوير وجود Python.

### Windows (PowerShell)

من مجلد المشروع:

```powershell
py -m http.server 8000 --directory src
```

ثم افتح:

```
http://localhost:8000
```

اترك نافذة الخادم مفتوحة أثناء التجربة، وأوقفه باستخدام `Ctrl+C`.

### Linux وmacOS

```bash
npm run serve
```

### فحص المشروع

```bash
npm run verify       # فحص سلامة المصدر ثم تشغيل الاختبارات
npm run smoke        # اختبار المتصفح الحقيقي؛ يحتاج Playwright والخادم يعمل
```

آخر نتيجة تحقق مسجلة للنسخة الرئيسية: **134 اختبارًا ناجحًا، و0 إخفاقات**.

## تجربة نسخة التطوير على الهاتف عبر Wi-Fi

1. شغّل الخادم على الكمبيوتر مع ربطه بجميع واجهات الشبكة:

   ```powershell
   py -m http.server 8000 --directory src --bind 0.0.0.0
   ```

2. اعرف عنوان IPv4 للكمبيوتر باستخدام `ipconfig`.
3. اتصل من الهاتف بالشبكة نفسها، ثم افتح `http://عنوان-الكمبيوتر:8000` في المتصفح.
4. اسمح لـ Python بالاتصال عبر جدار حماية Windows على الشبكات الخاصة عند ظهور الطلب.

هذه الطريقة تعرض الملفات المحلية الحالية من مجلد `src`، ولا تنشرها على GitHub Pages.

| Ctrl+C / X / V | نسخ / قص / لصق | L · W · R · C | خط · جدار · مستطيل · دائرة |

## الطباعة وجدول العنوان

من زر الطباعة اختر الورقة والاتجاه والمقياس، ثم أدخل بيانات المشروع والمالك وبيانات اللوحة. تُحفظ البيانات مع المشروع وتُضمّن في ملف JSON ضمن `meta`.

يمكن ضبط بيانات المكتب مرة واحدة من الإعدادات ← «تعديل بيانات المكتب»، لتظهر في اللوحات.

## النشر على GitHub Pages

- الدفع إلى فرع `main` مع تغيير في `src/` أو `tools/` يشغّل سير عمل النشر.
- يتحقق سير العمل من المصدر ويشغّل الاختبارات، ثم ينشر محتويات `src/` إلى فرع `gh-pages`.
- يجب ضبط GitHub Pages من إعدادات المستودع لاستخدام فرع `gh-pages` والمجلد الجذر `/`.
- طلبات الدمج إلى `main` تنشئ معاينة في المسار `preview/pr-<رقم>`.
- يُحدّث رقم إصدار الكاش في `sw.js` تلقائيًا أثناء النشر حتى تصل الملفات الجديدة إلى المستخدمين.

الموقع: https://smailmelki.github.io/MelkiCAD/

## بناء APK لأندرويد

يوفر سير العمل `.github/workflows/android-apk.yml` بناء APK من GitHub Actions. يمكن تشغيله يدويًا من Actions ← Run workflow، كما يعمل عند دفع تحديث إلى `main` أو إنشاء وسم إصدار يبدأ بـ `v`.

- **من دون أسرار التوقيع:** يُبنى APK تجريبي (Debug) قابل للتثبيت، ويُرفع كـ Artifact باسم `MelkiCAD-Android-Debug`.
- **مع أسرار التوقيع:** عند إعداد `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`، يُبنى APK إصدار (Release) موقّع باسم `MelkiCAD-Android-Release`.

يُضمّن APK ملفات `src/` الحالية داخل التطبيق، ولذلك يعمل دون اتصال بالإنترنت.

## عند تعديل الكود

- عند إضافة ملف JavaScript جديد، سجّله في `index.html` (وسم التحميل وخريطة الملفات في التعليق) وفي قائمة `CORE` داخل `sw.js`. يتحقق `tools/check.js` من ذلك.
- ملفات JavaScript تشترك في نطاق عام واحد؛ تجنب تكرار أسماء الدوال والمتغيرات العامة.
- أي نص مستورد قد يصل إلى `innerHTML` يجب تمريره عبر `esc()` المعرّفة في `01-core.js`.
- استخدم `redraw()` للرسم المؤجل أثناء حركة المؤشر أو العجلة، و`draw()` عندما تكون النتيجة الفورية مطلوبة.
- بعد تغيير بيانات المشروع استخدم `save()`؛ ولتغييرات العرض فقط استخدم `saveSoon()`.
- لا تستخدم `localStorage` مباشرة لبيانات التطبيق؛ استخدم `kvGet/kvSet/kvDel`.
- شغّل `npm run verify` قبل دفع أي تحديث.

## حدود معروفة

- الخط المضمّن بوزن Regular فقط؛ لذلك قد يعرض المتصفح النص العريض بوزن اصطناعي. لإضافة وزن SemiBold حقيقي، أضف ملف الخط إلى `src/fonts/` وسجّله في `CORE` داخل `sw.js`.
- تُحمّل المشاريع المحفوظة في IndexedDB إلى الذاكرة عند بدء التطبيق. كما أن حفظ المشروع الحالي يحوّله كاملًا إلى JSON؛ قد يكون ذلك ملحوظًا مع المشاريع الضخمة جدًا.
- هندسة PDF متجهية، أما النصوص (ومنها العربية) فتُدرج كصور عالية الدقة، لذلك لا يمكن تحديدها أو البحث داخلها. وإذا تعذر مسار الرسم المتجهي فقد يُستخدم إخراج صوري.
- استيراد DXF يتعرف تلقائيًا على UTF-8 و`$DWGCODEPAGE` وWindows-1256، لكن بعض ترميزات DOS ورموز `\\M+` متعددة البايتات غير مدعومة. وقد تُحوّل أسماء الطبقات غير اللاتينية عند التصدير إلى `Layer_N`، بينما تُصدّر النصوص نفسها بصورة سليمة.
- لا توجد مزامنة مباشرة بين نافذتين مفتوحتين للتطبيق؛ آخر عملية كتابة هي التي تسود.
- سجل التراجع يحتفظ بلقطات كاملة (حتى 100 لقطة)، وقد يستهلك ذاكرة أكبر في الرسومات الكبيرة جدًا.

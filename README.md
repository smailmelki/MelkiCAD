# MelkiCAD

تطبيق عربي (RTL) لرسم مخططات الغرف والمنازل يعمل في المتصفح كـ PWA بلا إنترنت، مع غلاف Android عبر Capacitor.
JavaScript خالص بلا مكتبات ولا خطوة بناء.

## البنية

```
src/                 كل ما يُنشر (index.html، sw.js، manifest، css/، js/)
  js/00…23-*.js      ملفات بنطاق عام واحد، الترتيب في index.html مهم (خريطة الملفات في أعلاه)
  js/00-storage.js   طبقة التخزين: IndexedDB بذاكرة مؤقتة متزامنة، ترحيل من localStorage، ووضع احتياطي
android-wrapper/     غلاف Capacitor (الجسر android-bridge.js يحوّل التصدير إلى نافذة حفظ أندرويد)
tools/check.js       فحص سلامة المصدر بلا اعتماديات
tools/test.js        اختبارات وحدة بلا متصفح (هندسة، التقاط، استيراد، تخزين، تراجع، DXF، اختصارات)
tools/smoke.js       اختبار دخان في متصفح حقيقي (اختياري، playwright)
.github/workflows/   ci.yml (فحص واختبار) · deploy-pages.yml (نشر) · android-apk.yml (بناء APK)
```

## التشغيل محليًا

```bash
npm run serve        # أو: python3 -m http.server 8000 -d src   ثم افتح http://localhost:8000
npm run verify       # فحص السلامة + الاختبارات (لا يحتاج تثبيت أي شيء)
npm run smoke        # اختبار المتصفح الحقيقي (يحتاج playwright والخادم يعمل)
```

## اختصارات لوحة المفاتيح (للحاسوب)

| الاختصار | الوظيفة | الاختصار | الوظيفة |
|---|---|---|---|
| Ctrl+Z / Ctrl+Y | تراجع / إعادة | V · H | تحديد · تحريك العرض |
| Ctrl+C / X / V | نسخ / قص / لصق | L · W · R · C | خط · جدار · مستطيل · دائرة |
| Ctrl+A | تحديد الكل | A · E · G · P | قوس · بيضاوي · مضلع · POLYLINE |
| Delete | حذف المحدد | F · T · D · M | رسم حر · نص · بُعد · تحريك المحدد |
| Esc | يتراجع خطوة (رسم ← قائمة ← تحديد) | F3 / F8 / F9 / F10 | التقاط بالنقاط / تعامد / شبكة / زاوية 45° |
| Enter | إنهاء POLYLINE | الأسهم · + · - · 0 | تحريك · تكبير/تصغير · ملاءمة |
| Ctrl+S / Ctrl+P | حفظ JSON / طباعة | ? أو F1 | قائمة الاختصارات |

تعمل بموضع المفتاح (`e.code`) فهي نفسها على لوحة المفاتيح العربية، ولا تعمل أثناء الكتابة داخل أي حقل.

## النشر

الدفع إلى `main` مع تغيير في `src/` أو `tools/` يشغّل `deploy-pages.yml`: يفحص ويختبر ثم ينشر `src/` إلى فرع `gh-pages`.
رقم إصدار الكاش في `sw.js` **يُختم تلقائيًا برقم الإيداع** عند النشر، فلا حاجة لرفعه يدويًا.
فعّل Pages من إعدادات المستودع على فرع `gh-pages`. طلبات الدمج تُنشر معاينةً في `preview/pr-<رقم>`.

## APK لأندرويد

شغّل `android-apk.yml` يدويًا (Actions ← Run workflow) أو أنشئ وسم إصدار `v*`. الـ APK يضمّن نسخة `src/` الحالية داخل التطبيق فيعمل بلا إنترنت.

- **بلا أسرار توقيع:** يُبنى APK تجريبي (debug) قابل للتثبيت، باسم `MelkiCAD-Android-Debug` في Artifacts.
- **مع الأسرار** `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`: يُبنى إصدار موقّع باسم `MelkiCAD-Android-Release`.

## عند تعديل الكود

- أضفت ملف JS جديدًا؟ سجّله في `index.html` (الوسم **وخريطة الملفات في التعليق**) وفي `CORE` داخل `sw.js`. `tools/check.js` يفشل إن نسيت.
- لا تكرّر اسم دالة أو متغير عام موجود في ملف آخر (النطاق مشترك): يفشل الفحص عند التكرار.
- أي نص قد يأتي من ملف مستورد (أسماء طبقات/مشاريع) ويدخل `innerHTML` يجب أن يمرّ عبر `esc()` (معرّفة في `01-core.js`).
- للرسم أثناء حركة المؤشر أو العجلة استخدم `redraw()` (مؤجَّل لإطار واحد)؛ `draw()` للأماكن التي تحتاج النتيجة فورًا.
- بعد تغيير بيانات المشروع استخدم `save()`؛ لتغييرات العرض فقط (تحريك/تكبير) استخدم `saveSoon()`.
- لا تستخدم `localStorage` مباشرة للبيانات: اقرأ واكتب عبر `kvGet/kvSet/kvDel`. وأي كود جديد يعتمد على المشاريع يجب أن يعمل بعد `Store.init()` (انظر `23-main.js`).
- شغّل `npm run verify` قبل أي دفع.

## حدود معروفة

- الخط (IBM Plex Sans Arabic) يُحمَّل من Google Fonts ويُخزَّن بعد أول فتح؛ أول تشغيل بلا إنترنت يستخدم خط النظام. الحل الأنظف: تضمين ملف الخط داخل `src/fonts/`.
- المشاريع تُحفظ في IndexedDB وتُحمَّل كلها إلى الذاكرة عند البدء (نصوص JSON). كل حفظ ما زال يحوّل المشروع الحالي كاملًا إلى JSON (نحو 33 مللي ثانية لمشروع 6.8 م.ب)؛ التحسين التالي للمشاريع الضخمة جدًا هو حفظ تفاضلي أو تحميل كسول للمشاريع غير المفتوحة.
- لا مزامنة بين نافذتين مفتوحتين للتطبيق: آخر كتابة تغلب (كما كان سابقًا).
- سجل التراجع يحفظ لقطة كاملة لكل خطوة (حتى 100)، وهو ثقيل في الرسومات الكبيرة جدًا.

# إعداد المزامنة السحابية في MelkiCAD

## 1. إنشاء مشروع Supabase
1. أنشئ مشروعاً جديداً من https://supabase.com/dashboard.
2. انتظر حتى تصبح قاعدة البيانات جاهزة.
3. افتح **SQL Editor** ثم أنشئ استعلاماً جديداً.
4. انسخ محتوى الملف `schema.sql` وشغّله. هذا ينشئ جدول المشاريع وسياسات RLS التي تمنع كل مستخدم من قراءة أو تعديل مشاريع غيره.

## 2. إعداد تسجيل الدخول
من **Authentication → Providers**:
- فعّل Email لتسجيل الدخول بالبريد وكلمة المرور.
- فعّل Google وأدخل بيانات OAuth Client من Google Cloud Console.
- اضبط عنوان الموقع وإعادة التوجيه في **Authentication → URL Configuration**. أضف عنوان GitHub Pages المنشور، ثم أضف عنوان APK/deep-link بعد اعتماد إعدادات غلاف Android.

قد يتطلب البريد تأكيد الحساب قبل أول دخول، بحسب إعدادات Supabase.

## 3. ربط MelkiCAD بالمشروع
من **Project Settings → API** انسخ:
- Project URL
- Publishable key (أو anon key القديم)

افتح MelkiCAD ثم **الإعدادات → الحساب والمزامنة السحابية**، والصق القيمتين واضغط **حفظ إعداد الاتصال**.

> استخدم المفتاح العام Publishable/anon فقط. لا تضع أبداً `service_role` أو أي مفتاح سري داخل تطبيق الويب أو APK.

## 4. طريقة العمل الحالية
- سجّل الدخول بالبريد أو Google.
- **رفع مشاريعي** يرفع المشاريع الموجودة على الجهاز إلى حسابك.
- **تنزيل مشاريعي** يجلب مشاريع الحساب إلى الجهاز.
- إذا وُجد مشروع بالمعرّف نفسه محلياً وسحابياً، سيطلب التطبيق تأكيد الاستبدال. صدّر نسخة JSON احتياطية قبل الموافقة.
- لا تُحذف النسخ السحابية تلقائياً عند حذف مشروع محلي؛ الحذف السحابي يحتاج إجراءً صريحاً لاحقاً.

## ملاحظات
- IndexedDB يبقى التخزين المحلي الأساسي، ولا يتوقف التطبيق عن العمل محلياً عند انقطاع الإنترنت.
- إعدادات Supabase تحفظ محلياً في كل جهاز؛ أدخل Project URL والمفتاح العام مرة واحدة على كل جهاز.
- هذا الإصدار يستخدم مزامنة يدوية فقط، ولا يرفع التعديلات تلقائياً.
